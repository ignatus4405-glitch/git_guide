# Журнал изменений курса

Формат — Keep a Changelog, версионирование — semver (см. урок `lesson:tegi-relizy-semver`).
Версия курса указана в `site.yml`. Автоматическая часть (состав модулей и уроков) фиксируется
в `docs/STATE.md` и `docs/MANIFEST.json` при каждой сборке.

## [1.0.0] — 2026-10-15

Первая полная версия курса: от установки Git до CI/CD, публикации сайта и безопасности.

### Добавлено

- **Инфраструктура курса.** Генератор статического сайта без внешних зависимостей:
  `build.py`, модули в `tools/` (markdown-рендерер, подсветка синтаксиса, шаблоны,
  модель контента, мини-парсер YAML, генератор диаграмм, валидатор, самотесты, локальный сервер).
- **Контент: 8 модулей, 24 урока** — основы Git, история и ветки, GitHub и Pull Request,
  командная работа, GitHub Actions, Pages, безопасность, продвинутые приёмы.
- **Страницы материалов:** карта курса, шпаргалка команд, словарь терминов,
  20 типичных ошибок с решениями, итоговый экзамен (30 вопросов), список ресурсов.
- **13 SVG-схем**, генерируемых кодом (`tools/gen_diagrams.py`): три «дерева» Git,
  устройство коммита, ветвление, merge против rebase, конфликты, отмена, путь Pull Request,
  пайплайн Actions, модели ветвления, слои безопасности, анатомия урока, синхронизация форка,
  большие файлы и подмодули.
- **Поиск по курсу**, прогресс по урокам в браузере, светлая и тёмная темы,
  оглавление страницы, кнопки копирования кода, интерактивные вопросы самопроверки.
- **CI/CD на GitHub Actions:** `ci.yml` (проверка контента → самотесты → сборка → артефакт),
  `pages.yml` (публикация на Pages с проверкой включения Pages), `docs-sync.yml`
  (автообновление `docs/STATE.md` и `docs/MANIFEST.json`), `healthcheck.yml`
  (еженедельная проверка с созданием issue при сбое).
- **Документация для продолжения работы:** `AGENTS.md` (протокол правок и инварианты),
  `docs/CONTENT_GUIDE.md` (формат контента), `docs/ARCHITECTURE.md` (устройство генератора),
  `docs/STATE.md` и `docs/MANIFEST.json` (генерируемая карта репозитория),
  шаблоны issue и Pull Request, `CODEOWNERS`, `CONTRIBUTING.md`, `LICENSE` (MIT).
- **Качество:** валидатор контента и ссылок (105 проверок), 35 самотестов сборки,
  `.gitattributes`, `.editorconfig`, `pre-commit`-конфигурация, Dependabot для Actions.

### Примечания

- Курс собирается на «голом» Python 3.10+: сторонних пакетов нет.
- Для публикации сайта нужно один раз включить Pages (Settings → Pages → Source: GitHub Actions):
  workflow `pages.yml` сам сообщит об этом в сводке прогона.

## Как вести журнал дальше

```markdown
## [1.1.0] — ГГГГ-ММ-ДД

### Добавлено
- …

### Изменено
- …

### Исправлено
- …
```

Правило проекта: изменение без записи здесь считается незавершённым
(см. `AGENTS.md`, раздел «Что обновлять после каждого изменения»).
