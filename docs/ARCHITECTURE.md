# Архитектура

## Обзор

Приложение — нативное WPF-приложение для Windows на .NET 8. Оно не обращается к сети и не зависит от внешних библиотек. Пользователь скачивает ZIP из GitHub Actions, распаковывает его и запускает `GitHubCourse.exe`.

## Поток данных

1. `Course/lessons.json` — единственный источник текстов, команд, схем, практики, вопросов и объяснений.
2. `GitHubCourse.csproj` включает JSON в сборку как embedded resource `GitHubCourse.Course.lessons.json`.
3. `Services/CourseService.cs` десериализует ресурс в классы `Models/` при запуске приложения.
4. `MainWindow.xaml.cs` строит навигацию и страницы уроков из модели. Тексты не дублируются в коде интерфейса.
5. `Services/ProgressStore.cs` хранит список завершённых ID уроков в `%LOCALAPPDATA%\GitHubCourse\progress.json`. Повреждённый файл прогресса сбрасывается без блокировки курса; секреты там не хранятся.

## Интерфейс

`MainWindow.xaml` задаёт двухколоночное окно: тёмная навигация слева и область урока справа. Code blocks отображаются моноширинным шрифтом, notes и упражнения — отдельными карточками. Диаграммы — встроенные векторные WPF-карточки со стрелками: они собираются из `diagram.steps` каждого урока, поэтому внешние изображения и интернет для просмотра не требуются. Контрольный вопрос проверяется локально; в файл прогресса сохраняется только факт прохождения урока.

## Проверки и сборка

- `scripts/validate_course.py` проверяет обязательные поля, уникальность ID, блоки, схемы и тесты.
- `tests/test_course_content.py` проверяет курс и покрытие важных Git/GitHub-команд.
- `.github/workflows/build-windows.yml` запускает проверки Python на Ubuntu и сборку на `windows-latest`.
- Windows job выполняет self-contained `dotnet publish` для `win-x64`, включает single-file publish и загружает ZIP-артефакт на 14 дней.

## Ограничения текущей версии

- Артефакт рассчитан на Windows x64; сборок для ARM64 и macOS нет.
- Исполняемый файл не подписан сертификатом издателя.
- Прогресс хранится только на текущем компьютере; синхронизации и профиля пользователя нет.
- Содержание курса и тесты русскоязычные; мультимедиа загружается не из сети.
