## 2026-10-15 — исправление по первой Windows-сборке CI

- Первая Actions-сборка выявила отсутствующие ссылки на `System.IO` в сервисах загрузки курса и прогресса; добавлены явные импорты, чтобы сборка не зависела от implicit usings SDK.
- Повторная проверка Python и Windows publish запускается новым push.

## 2026-10-15 — первая версия приложения и курса

- Создано WPF-приложение для Windows на .NET 8 с русским интерфейсом, поиском, навигацией и индикатором прогресса.
- Добавлено 21 урок: от установки и настройки Git до веток, PR, конфликтов, Actions, Releases, fork, безопасности, GitHub CLI и диагностики.
- Для каждого урока добавлены встроенная схема, практическое задание и тест с объяснением ответа.
- Добавлено локальное сохранение выполненных уроков; приложение не требует входа и работает офлайн.
- Настроен GitHub Actions workflow: проверка контента и Python-тесты на Ubuntu, self-contained Windows x64 publish на Windows, ZIP-артефакт в запуске Actions.
- Добавлены инструкции по сборке, архитектуре, продолжению разработки и добавлению уроков.
- Проверки в локальной среде: `python scripts/validate_course.py` и `python -m unittest discover -s tests -v` — пройдены. Сборка WPF поручена Windows runner в GitHub Actions.
