Git и GitHub — инструменты, но работают ими люди. Этот модуль о процессах, которые
превращают поток коммитов в понятный проект: как формулировать задачи, как проверять
чужой код и как договариваться о правилах, чтобы слияния не превращались в разбор конфликтов.

**Что вы унесёте из модуля:**

- чек-лист ревью и умение писать замечания, которые не обижают;
- структуру задач: Issue → ветка → PR → релиз;
- шаблоны репозитория: PR-шаблон, issue-шаблоны, CODEOWNERS, CONTRIBUTING.
