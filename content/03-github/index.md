Git работает локально. GitHub добавляет то, что превращает набор личных репозиториев
в совместную работу: удалённые копии, обсуждения, ревью, права и автоматизацию.

**После модуля вы сможете:**

- связать локальный репозиторий с GitHub и синхронизировать изменения без сюрпризов;
- провести полный цикл Pull Request: ветка → push → PR → ревью → merge;
- выбрать стратегию слияния (merge, squash, rebase) и понимать последствия;
- настроить защиту ветки, чтобы в `main` не попадал нерабочий код;
- делать всё то же самое из терминала через `gh` CLI.

::: info Как читать этот модуль
Скриншоты интерфейса не нужны: любое действие в веб-интерфейсе GitHub дублируется
через API или `gh` CLI, а эти команды не устаревают так быстро, как кнопки в UI.
:::
