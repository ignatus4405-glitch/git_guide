## Как устроен курс

Материал идёт от простого к сложному: сначала вы разбираетесь, что такое коммит и почему
Git называют распределённой системой, затем учитесь работать с историей и ветками, подключаете
удалённые репозитории, проходите ревью и заканчиваете автоматизацией: CI/CD, публикацией
сайта и безопасностью.

**Три принципа, по которым он собран:**

1. **Каждая команда объясняется на уровне модели.** Вы понимаете, *почему* `git add`
   отличается от `git commit`, а не заучиваете последовательность символов.
2. **Всё проверяемо.** В курсе нет «магии»: любой результат можно воспроизвести локально,
   а вывод команд — сверить со своим терминалом.
3. **Материал — это код.** Уроки лежат в markdown, схемы генерируются кодом, сайт собирается
   и проверяется автоматически. Ошибку в тексте находит CI, а не читатель.

## Что вы будете уметь в финале

- создавать репозиторий, делать осмысленные коммиты и читать историю как граф;
- работать с ветками, разрешать конфликты, осознанно выбирать между `merge` и `rebase`;
- безопасно отменять изменения (`restore`, `reset`, `revert`, `reflog`) и понимать последствия;
- проводить полный цикл Pull Request и ревью, использовать GitHub Issue и Projects;
- настраивать защиту веток, `CODEOWNERS` и шаблоны репозитория;
- писать workflow GitHub Actions: проверки, матрицы, кэш, артефакты, секреты;
- публиковать статический сайт на GitHub Pages напрямую из Actions;
- защищать проект: ключи, токены, Dependabot, secret scanning, чистка истории.

## С чего начать

- Первым делом прочитайте [«Карта курса»](page:karta-kursa) — это оглавление со временем чтения по каждому уроку.
- Если вы совсем новичок, начните с модуля «Основы Git» — там ставим Git и делаем первый коммит.
- Если уже работаете с Git, но хотите проверить пробелы, начните с [шпаргалки](page:shpargalka) и перейдите к модулям 5–8.
- Перед началом полезно полистать [словарь терминов](page:slovar): там короткие определения для всех понятий курса.

## Про работу курса как проекта

Курс — это настоящий инженерный проект: свой статический генератор, тесты, проверка ссылок,
CI на GitHub Actions и автосборка сайта при каждом push. Разбор этих же workflow есть в
модуле «GitHub Actions» — вы увидите не выдуманные примеры, а код, который собирает то,
что вы сейчас читаете.
