GitHub Actions — это встроенный CI/CD. Событие в репозитории запускает workflow:
набор задач (jobs), каждая состоит из шагов (steps), выполняющихся на удалённой машине
(runner). Ваши проверки, сборки и публикации перестают зависеть от того, помнит ли
разработчик запустить их локально.

**После модуля вы сможете:**

- писать workflow на YAML и объяснять разницу между `on`, `jobs`, `steps`;
- запускать сборку по push, по Pull Request, по расписанию и вручную;
- использовать матрицу версий, кэш зависимостей и артефакты;
- безопасно работать с секретами и правами токена `GITHUB_TOKEN`;
- читать зелёный и красный прогон и понимать, что именно нужно исправить.

::: success Практика на живом примере
Каждый урок модуля опирается на реальные workflow этого репозитория: они проверяют
контент, запускают тесты, собирают сайт и публикуют его. Откройте каталог
`.github/workflows/` и читайте код вместе с курсом.
:::
